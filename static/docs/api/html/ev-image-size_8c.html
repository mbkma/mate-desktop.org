◆ ev_image_size_from_header()

EvImageSizeResult ev_image_size_from_header ( const guchar * data,
gsize len,
gint * width,
gint * height )

ev_image_size_from_header: @data: the first bytes of an image file @len: the number of bytes in @data @width: (out): where to store the image width @height: (out): where to store the image height

Reads the size of a JPEG, PNG, GIF or WebP image from the first bytes of its file, without decoding the image.

Returns: EV_IMAGE_SIZE_FOUND if @width and @height were set, EV_IMAGE_SIZE_NEED_MORE if @data is too short to tell, or EV_IMAGE_SIZE_UNKNOWN if the format isn't supported or the header is invalid.
