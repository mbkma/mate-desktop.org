#define MATE_DESKTOP_USE_UNSTABLE_API

SECTION:mate-monitor-info @short_description: monitor ids and facts for MATE desktop components

#MateMonitorInfo answers, for each #GdkMonitor, what the panel, the file manager's desktop and the preferences need: the monitor id that per-monitor settings are stored under, a name to show, whether it is built in, the primary monitor, mirroring, the work area and who draws the desktop background.

On a Wayland compositor that offers mate_output_manager_v1 (see mate-wayland-protocols) the answers come from the compositor. Otherwise they come from GDK: the id is the monitor's make and model, numbered "+1", "+2" by position for duplicates; the work area is gdk_monitor_get_workarea(); the background owner is unknown and no capability is reported.

void mate_monitor_info_migrate_settings ( MateMonitorInfo * info,
GdkMonitor * monitor,
const gchar * schema_id,
const gchar * path_prefix )

mate_monitor_info_migrate_settings: @info: a #MateMonitorInfo @monitor: a #GdkMonitor @schema_id: a relocatable schema, such as "org.mate.background.monitor" @path_prefix: where its per-monitor copies live, ending in "/", such as "/org/mate/desktop/background/monitors/"

Copies @monitor's settings from its fallback id to its id, once: only when the two ids differ, the fallback path holds values and the new path holds none. The fallback path is never changed, so going back to a session without the protocol finds the old settings.
