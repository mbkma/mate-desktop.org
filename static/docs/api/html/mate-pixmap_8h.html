gint width,
gint height )

mate_pixmap_new_from_file_at_size: @filename: The filename of the file to be loaded. @width: The width to scale the image to. @height: The height to scale the image to.

Loads a new @MatePixmap from a file, and scales it (if necessary) to the size indicated by @height and @width. If either are set to -1, then the "natural" dimension of the image is used in place. See @mate_pixmap_new_from_file for information on error handling.

Return value: value: A newly allocated @MatePixmap with the file at @filename loaded.
